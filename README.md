# 🔍 Ethical Network Scanner

A Python-based ethical network security scanner designed for authorized security assessments and defensive cybersecurity learning.

The tool helps identify active hosts, open ports, running services, and operating system information, with results available in JSON format for further analysis.

## ⚠️ Legal & Ethical Use

This project is intended **only for systems, networks, and devices that you own or have explicit permission to test**.

Do not use this scanner against unauthorized systems or networks.

## ✨ Features

- 🔎 Host discovery
- 🔌 Port scanning
- 🛠️ Service detection
- 💻 Operating system detection
- 📄 JSON report generation
- 🛡️ Designed for authorized security assessments
